# OnPC_Calc

OnPcCalc is a program that calculates how much time the user spends running the PC and on each application. It provides a simple GUI to start tracking and to view the stored statistics.

## Features

- Start and stop tracking of the currently running processes.
- Store daily summaries in an SQLite database.
- View tracked data for any day using a drop down menu.
- Print the displayed data.

## Usage

Install the requirements and run `main.py`:

```bash
pip install -r requirements.txt
python main.py
```
